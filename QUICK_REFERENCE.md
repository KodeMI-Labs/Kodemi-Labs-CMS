## 📡 API Endpoints

### Reviews
| Method | Endpoint | Purpose |
|--------|----------|---------|
| POST | `/courses/{courseId}/reviews` | Create with validation |
| GET | `/courses/{courseId}/reviews` | Get by course (fast) |
| GET | `/course-review/{review_id}` | Get specific |
| GET | `/course-review/all` | Get all |
| PUT | `/course-review/update/{review_id}` | Update |
| DELETE | `/course-review/delete/{review_id}` | Delete |

### Ratings
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/courses/{courseId}/rating-summary` | Get aggregation |

## 🔗 Microservice Integration

**Service**: Course Microservice  
**URL**: http://localhost:8088  
**Endpoint**: GET /courses/{courseId}/exists  
**Returns**: boolean (true = course exists)

### Fallback Behavior
If Course MS is down:
- Returns `true` (graceful degradation)
- Allows reviews to be created
- Logs warning message

## 🛠️ Configuration Options

### In application.yaml
```yaml
aws:
  accessKey: ${AWS_ACCESS_KEY_ID:your_aws_access_key_here}
  secretKey: ${AWS_SECRET_ACCESS_KEY:your_aws_secret_key_here}
  region: ${AWS_REGION:ap-south-1}

dynamodb:
  use-local: false    # Set to true for local
  endpoint: http://localhost:8000

server:
  port: 8087
```

### Environment Variables
```bash
export AWS_ACCESS_KEY_ID=your_aws_access_key_here
export AWS_SECRET_ACCESS_KEY=your_aws_secret_key_here
export AWS_REGION=ap-south-1
```

## ⚙️ Troubleshooting

### DynamoDB Connection Failed
```
✓ Check credentials
✓ Check internet
✓ Check region
✓ Verify IAM permissions
```

### Course MS Unreachable
```
✓ Check Course MS running on 8088
✓ Verify connectivity
✓ Fallback is active (reviews still work)
```

### Tables Not Created
```
✓ Check application logs
✓ Verify credentials have permissions
✓ Check region ap-south-1
✓ Manual creation via AWS console
```

### GSI Not Found
```
✓ Delete CourseReview table
✓ Restart application
✓ Or manually add via AWS console
```
